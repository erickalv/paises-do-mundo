# Países do Mundo

Globo interativo para estudar os 255 países e territórios: digite o nome e ele aparece colorido no globo, com bandeira.

- **Iniciar:** partida com contador e cronômetro.
- **Treino:** sem cronômetro; o botão do olho mostra todos os países e, tocado de novo, recomeça do zero.
- **História:** linha do tempo de 1976 a 2026; arrastando para o passado, o globo mostra as fronteiras, nomes e bandeiras de cada ano (situação em 31 de dezembro), com as fronteiras de hoje em traço fraco.
- Funciona offline e pode ser instalado na tela inicial pelo Chrome ("Instalar app").

Mapa: Natural Earth (via world-atlas). Bandeiras: flag-icons. Dados dos países: world-countries.
